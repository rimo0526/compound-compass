5kg痩せるのに何ヶ月かかる？体重別の現実的な期間と必要カロリー

2026年5月7日 ・ 複利コンパス編集部

「5kg痩せたい！…で、何ヶ月かければいいの？」

ネットでは「2週間で5kg」「1ヶ月で5kg」など過激な情報も見かけますが、それは健康的に痩せる方法ではありません。WHO推奨は週0.5〜1kg、つまり5kg減には最低5週間〜10週間必要です。

本記事では、現体重別に「健康的に5kg減量する期間」を、必要カロリー・成功確率を含めて具体的に提示します。

結論：3〜5ヶ月で5kg減が現実的

  • 3ヶ月（13週）：週0.4kgペース → やや積極的（成功率60%）
  • 4ヶ月（17週）：週0.3kgペース → 健康的（成功率80%）
  • 5ヶ月（22週）：週0.2kgペース → 最も継続しやすい（成功率85%）
  • 2週間〜1ヶ月：週1.2kg超のペース → 健康リスク大、リバウンド確率高

1. 5kg減量に必要なカロリー

体脂肪1kg ≈ 約7,200kcal。つまり5kg減量には総量36,000kcalを消費する必要があります。

期間別の1日あたり必要カロリー削減

期間1日の必要削減難易度
2週間（14日）−2,571kcal/日不可能・危険
1ヶ月（30日）−1,200kcal/日健康リスク大
2ヶ月（60日）−600kcal/日かなり大変
3ヶ月（90日）−400kcal/日健康的・継続可
4ヶ月（120日）−300kcal/日楽勝・推奨
6ヶ月（180日）−200kcal/日超穏やか

−400kcal/日は「ご飯1膳分（200kcal）+ 1時間ウォーキング（200kcal）」で実現可能。3ヶ月プランが最も現実的です。

2. 体重別 5kg減のインパクト

同じ「5kg減」でも、現体重によって体への影響と難易度が違います：

現体重5kg減後減少率備考
50kg → 45kg45kg10%健康な範囲なら不要かも
60kg → 55kg55kg8.3%適度・継続なら可能
70kg → 65kg65kg7.1%標準的な目標
80kg → 75kg75kg6.3%比較的簡単（脂肪多め）
90kg → 85kg85kg5.6%最初の5kgは出やすい

体重が重いほど最初の5kg減は比較的簡単。これは脂肪量が多く、わずかなカロリー制限で大きな変化が出るため。

3. 健康的に5kg減らす実践プラン（3ヶ月プラン）

食事面（−250kcal/日）

  • 主食を1割減（ご飯200g → 180g）= −36kcal
  • 砂糖入り飲料をゼロに（1日500mlの清涼飲料カット）= −200kcal
  • 夕食の揚げ物を週2回に（揚げ物 → 焼き物・蒸し物）= 平均 −50kcal
  • 合計 約 −280kcal/日

運動面（−150kcal/日）

  • 毎日30分のウォーキング（時速5km）= 約 100kcal
  • 週末1時間のジョギング or サイクリング（ピーク日に追加）
  • 1日平均 約 150kcal

合計で −400kcal/日達成

これを継続すれば、3ヶ月で5kg減が現実的に達成可能。劇的な節制ではなく、継続できるレベルに調整するのがコツ。

4. やってはいけないダイエット

⚠ 健康リスクのあるダイエット例
  • 1日500kcal以下の極端な絶食 → 基礎代謝低下、リバウンド必至
  • 炭水化物完全カット → エネルギー不足、頭痛、集中力低下
  • 2週間で5kg減を目指す → ほぼ水分減、再水分摂取で即戻る
  • 下剤・利尿剤の使用 → 脱水、内臓ダメージ
  • 過剰な有酸素運動（毎日2時間以上） → 関節障害、ホルモンバランス崩れ

リバウンドする人の3つの共通点

  1. 短期決戦：1ヶ月以内など極端な期間設定
  2. 食事だけ：運動なしの極端食事制限は基礎代謝が落ちる
  3. ゴール設定が「体重だけ」：習慣化なきゴールは戻る

5. 5kg減って見た目はどう変わる？

  • 顔のむくみが取れる（5kgのうち1〜2kgは水分）
  • ウエストが−5〜8cm（脂肪減で内臓周りもスッキリ）
  • 服のサイズが1段階下がる（M → S、L → M）
  • 体力が向上（階段で息切れしなくなる等）

体重計の数字以上に、見た目・体感の変化が大きいのが5kg減の特徴。継続のモチベになります。

6. まとめ

  • 5kg減は3〜5ヶ月で達成が健康的
  • 必要カロリー削減は1日−400kcal（3ヶ月プラン）
  • 食事と運動の組み合わせ（食事7：運動3 程度）が継続しやすい
  • 2週間で5kgは不可能、健康リスク大
  • 体重重い人ほど最初の5kgは出やすい

ダイエットは「短期決戦」より「習慣化」。3ヶ月プランで5kg減できれば、その後の体重維持もしやすくなります。
